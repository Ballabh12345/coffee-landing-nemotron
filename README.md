# Coffee Landing Page — Model Test: "nemotron"

Fully offline-ready: all libraries vendored locally in `vendor/` and the JSX is pre-compiled.
Open `index.html` in any browser — no internet needed (only the photos require it; graceful gradient fallback otherwise).

**Stack:** React 18 (UMD production) + Tailwind CSS (local) + Lucide icons (local).
**Brand:** NOIR CAFÉ — Espresso & Atelier (fictional).
**Typography:** Playfair Display (serif, italic headlines) + Outfit (sans).
**Art direction:** Dark espresso luxury —
- Ink/espresso hero with cream serif italic headlines and arch-masked photography
- Thin gold divider rules, gold CTA buttons, vertical side cues
- Signature menu with price badges on image cards
- Split story with year badge, parallax atelier band
- Dotted-leader bakery menu, tabbed testimonials, contact with map
